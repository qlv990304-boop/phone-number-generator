Test the Seattle and Washington state combination

For an address in Washington, Seattle, the state field is WA. This page keeps that Seattle tuple fixed so a mock form can distinguish Washington state from Washington, DC. It is one Washington page with a Seattle preset, not two separate pages for the same Seattle intent.

Full text versus fields

Copy the formatted address for a mockup. Use the JSON or CSV fields for automated checks instead of parsing the display text. Verify that state_name is Washington while country remains US.

This is the location assertion used in our own offline batch check. Apply it to every generated row, then keep street and apartment assertions separate:

row.state === "WA" && row.state_name === "Washington" && row.city === "Seattle" && row.postal_code === "98104"

That assertion checks the generator's field contract. It cannot establish that the street exists, that a unit is occupied or that a carrier will deliver mail. The generator uses Example, Test, Sample and Demo street markers so the invented portion remains visible.

Source and coverage of the Seattle preset

The Seattle City Council visiting City Hall page documents the combination Seattle, WA 98104. Our dataset uses only that city/state/ZIP combination. It does not reproduce the office street address, copy residents or import property records.

The ZIP is one sourced preset, not a code for every address in Seattle or Washington. Pairing it with invented street text creates a test sample, not a validated postal address. USPS Publication 28 describes complete, standardized addresses in relation to postal address files. A matching format alone does not provide that validation.

Washington address generator FAQ

Are these real Washington addresses?

No verified delivery address is produced. The city/state/ZIP combination is sourced, while the street and optional unit are invented test text. No residence, property or mailbox is checked.

Does this generate addresses across all of Washington?

No. It currently offers one Seattle, WA 98104 preset. It is not a statewide address directory, a Washington, DC generator or a complete Seattle ZIP dataset.

Can I use the result for shipping or proof of residence?

No. Use the actual authorized recipient or residence information for those purposes. This tool supplies fixtures for offline tests and demos.

Can I repeat a generated batch?

Yes. Expand the seed control, enter a label, and keep the seed, quantity and apartment choice. Repeat with the same dataset version. Without a seed, pressing Generate creates a fresh sample.

Do I need to register or install anything?

No. Use this page in a browser with JavaScript enabled. Copy, JSON and CSV controls work locally.
