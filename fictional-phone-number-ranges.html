Reviewed safety matrix

Fictional phone number ranges and structural test fixtures

A valid-looking phone number is not automatically fictional. This reviewed matrix makes the safety difference explicit for every country currently supported by GetPhoneNum.

Reviewed by GetPhoneNum Editorial Team · Updated August 2, 2026

The result of our 31-country review

Only 4 records in the current dataset are backed by a published reserved, drama or creative-work example. 27 records describe a national shape but may overlap an assigned subscriber. That ratio is the most important result of this review: formatting accuracy and contact safety are different properties.

Use documented creative-use examples for screenshots, tutorials and local fixtures. For structural examples, disable outbound SMS and voice, use sandbox credentials and block real delivery at the provider or network boundary.

What “reserved” does and does not mean

A regulator may reserve a narrow range for drama, media or examples. That does not make every number with the same area code fictional, and it does not authorize contacting the range. Always keep the complete published pattern. If a source publishes individual example numbers rather than a block, use only those examples.

Shared calling plans need extra care. The +1 plan covers multiple countries and territories, while +7 is shared by Russia and Kazakhstan. A calling code can identify a numbering area without proving a specific country.

How to use structural fixtures safely

  1. Generate only inside local development, isolated staging or a test runner.
  2. Disable real delivery and use provider sandbox credentials.
  3. Maintain an explicit allowlist for any integration capable of calling or sending SMS.
  4. Store the fixture's region and safety label beside the value.
  5. Never use generated data for lead lists, account creation or OTP collection.

The browser generator runs locally, but copying its output into a production communications system changes the risk. Safety depends on the entire test environment, not only the string.
