How to dial internationally

Replace the domestic international-access prefix with +, add the country calling code, and normally remove the domestic trunk prefix. Exact rules vary by country and service.

Calling code is not always a country

Some calling codes are shared. +1 covers the North American Numbering Plan, and +7 is shared by Russia and Kazakhstan. A prefix match can identify a calling plan without proving one country.

Do not remove every leading zero

A domestic trunk zero is commonly removed before an international code, but the rule is not universal. Italian geographic numbers are a well-known reason to parse with country metadata instead of a global string replacement.

Use current sources

Country guides link to regulators, numbering administrators or ITU references. Check those sources or a maintained library before enforcing rules in production because allocations and lengths can change.

Example lookup workflow

  1. Keep the leading + or convert an international access prefix such as 00.
  2. Match the longest supported calling code, not only the first digit.
  3. Use the remaining national digits and selected country context to resolve shared plans.
  4. Format for display only after storing one canonical representation.
