Phone test-data API

We are validating a small API for repeatable international phone fixtures—not live numbers, SMS reception or subscriber lookups.

Not yet generally available. This page documents the proposed MVP so developers can tell us whether it solves a real testing problem.

Deterministic output

Provide a seed and receive the same fixtures on every test run.

Positive and negative cases

Generate valid-format examples alongside wrong-length, missing-code and boundary cases.

Developer-friendly formats

Return E.164, national, international and RFC 3966 values in JSON.

Proposed request

POST /v1/generate

{
  "countries": ["US", "GB"],
  "quantity": 25,
  "formats": ["E164", "NATIONAL"],
  "seed": "checkout-tests",
  "include_invalid_cases": true
}
