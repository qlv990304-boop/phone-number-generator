Create a fake American address for a test form

Choose a city preset, set a quantity, and generate a synthetic street address. Each result includes street, optional apartment, city, two-letter state, full state name, ZIP Code and country. Copy gives you the formatted text; JSON and CSV keep each field separate.

The generator's first release has five city presets. “Any of the 5 presets” chooses among those records. It does not offer every US city, every state or every ZIP Code, and it does not look up a person's address.

City, state and ZIP stay together

The location fields come from the source-linked presets below. Only the city/state/ZIP combination is used; the real street addresses on those reference pages are not copied into this tool. Street and unit text are created from an authored test vocabulary.

Copy one address or export a small batch

  1. Select a city or leave the five-preset option selected.
  2. Choose 1, 5, 10 or 25 records and enable apartment units when needed.
  3. Press Generate address and check the result's location fields.
  4. Copy the address text, or download JSON/CSV for your form fixtures.

Within a batch, the generator avoids repeating the same city and street line. Separate batches can repeat. If you need to reproduce a batch, expand the seed option and keep the same seed, city, quantity and unit setting. Dataset changes can alter the outputs, so preserve the exported dataset version with a long-lived test.

A useful first run is five samples without units for a basic form, followed by five with units for a second-line test. Keep generated results in your test environment rather than entering them into a real shipping or billing flow.

What is inside the JSON and CSV?

The export contains address_line_1, address_line_2, city, state, state_name, postal_code and country. It also includes the synthetic-data label, delivery-verification status, dataset version and location reference.

Separate the unit

An apartment belongs in line 2. When the option is off, that field is an empty string.

Preserve ZIP text

The JSON ZIP value is a string. Keep postal codes as text when importing CSV into a spreadsheet or database fixture.

Keep the context

Retain synthetic and delivery_verified so an exported sample stays clearly identified as test data.

For spreadsheet imports, the CSV text-preservation guide explains why CSV quoting does not set a spreadsheet column's type. The same import decision matters for postal-code fields.

American address shape is not delivery validation

This tool gives you a familiar US-style address block for a mockup. It does not run USPS verification, check a resident, confirm a business or validate a payment address. USPS Publication 28 describes the additional address-file validation involved in a complete standardized mailing address.

Street names include an Example, Test, Sample or Demo marker. They are invented for this tool, but the generator cannot guarantee that an arbitrary text combination has never been used as a real address. Treat all results as unverified synthetic samples.

Fake address America FAQ

Is this a free US address generator?

Yes. You can generate samples, copy them and download JSON or CSV without an account.

Are the addresses fake or real?

Street and unit values are authored synthetic data. The city/state/ZIP fields are fixed location presets. No generated address is checked for existence or delivery.

Does it cover all 50 states?

No. This initial release has five city presets in California, Washington, Pennsylvania, Alabama and Tennessee. The selector shows exactly what is available.

Can I use these for account, residence or billing verification?

No. A generated address is not evidence of a person's residence, billing details or identity.

How do I generate only Los Angeles addresses?

Choose Los Angeles in the selector or open the dedicated Los Angeles addresses page.

Where are the samples generated?

Generation runs in your browser. Generated address values are not submitted to GetPhoneNum.
