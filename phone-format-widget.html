Country phone format widget

Add country calling codes, national patterns and E.164 examples to your documentation or developer site with one iframe.

Live preview

Embed code

Copy this HTML into the page where the reference should appear. Change country=GB to any supported ISO 2-letter code, such as US, MX, SG or AE.

<iframe
  src="https://getphonenum.com/embed/phone-format?country=GB"
  title="Country phone format reference"
  width="100%"
  height="330"
  loading="lazy"
  style="border:0"
></iframe>
